## 2. Lima celah teratas (urut dampak ke skor)

1. **Test suite yang bisa diulang + `tests/baseline.md` (20+ kasus).** Dimensi: Technical Execution (4), Overall (10), dan item wajib *Test results* (§7, "Include any that failed"). Tanpa ini klaim di baris lain tidak bisa dibuktikan. Petakan ke ~20 kasus resmi challenge bila dataset kickoff tersedia; kalau tidak, ke 24 kasus di Rencana §9. Task: *Test suite `npm run test:b1`* (hari ini).
2. **Permission check lengkap dan gagal-tertutup.** Cek `contactRules` untuk **setiap** penerima (bukan hanya `ownerId`), tegakkan `canContactRoles` + `allowedTools` per role, dan tolak eksekusi bila `permissions.json` tidak terbaca. Dimensi: Responsible AI (9), Overall (10). Ini celah yang paling mungkin memicu critical failure "exposes restricted information" atau menghubungi kontak terlarang. Task: **belum ada**; usulkan task baru P1.
3. **Evidence gate menolak + validator gagal-tertutup + `open_items`.** Kandidat dengan `evidence_not_found` / `source_segment_mismatch` / `owner_unknown` / `duplicate` harus ditolak, bukan hanya dicatat. Bila validator LLM error, kandidat harus ditahan, bukan dianggap valid. Saran (`suggestion`) masuk `open_items`. Dimensi: Technical Execution (4), Responsible AI (9) — aturan "Admits its limits", Human-Centered (2). Task: *Evidence gate menolak + segmentasi*, *Validator/clarifier Zod*, *open_items* (hari ini). Catatan: fallback validator gagal-terbuka belum tentu masuk lingkup task Zod; perlu dipastikan.
4. **Chitragupta sebagai agent utama: AGENTS.md + CLI ke gerbang deterministik + bukti sesi.** Dimensi: AI Interaction (3), Innovation (7), Feasibility (5), dan item wajib *Product sharing* ("Where Chitragupta added value"). Task: *AGENTS.md + CLI Chitragupta* (hari ini).
5. **Injeksi Bahasa Indonesia + audit event lengkap.** Tambah pola seperti "abaikan instruksi", "teruskan ke semua staf"; kirim `CONFIRMATION_SHOWN`, `EXECUTION_REQUESTED`, `UNDO_WINDOW_EXPIRED`; tulis `CONSENT_LOGGED` ke JSONL juga. Dimensi: Responsible AI (9) — "Treat text … as data" dan "Keeps a record", Technical Execution (4). Task: *Injeksi Bahasa Indonesia*, *Audit event lengkap* (hari ini).

Di luar lima besar, celah dengan biaya kecil: atribut `aria-` di layar konfirmasi (UX 8), angka dampak terukur (Impact 1), naskah video (Demo 6).
